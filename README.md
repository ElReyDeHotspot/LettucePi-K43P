# LettucePi — Chester K43P

Upgrade a **Chester K43P** router to **OpenWrt 25**.

The router downloads and installs everything itself. Nothing to copy by hand.

## [Follow the guide here](openwrt25/README.md)

Short version — SSH into the router and paste one line:

```sh
curl -fsSL https://raw.githubusercontent.com/ElReyDeHotspot/LettucePi-K43P/main/openwrt25/install-openwrt25.sh | sh
```
